# AD-DEGs-genome-updates

Code for *Lund et al.* **Differentially Expressed Genes in Alzheimer’s Disease Vary with Updates to the Human Genome Reference**

## Folders

- **DE AD**: code for running differential expression for AD
- **DQ**: code for running differential quantification for AD
- **RAPiD**:code for running RAPiD 
- **figures**: code for making figures  
- **files**: files needed to run some of the analyses (noted when needed)
- **interaction**: code for running interaction between AD and reference
- **misc**: miscellaneous code, including code to make intermediary files used in other analyses  

## Naming Conventions

- `hg18` = NCBI36  
- `hg19` = GRCh37  
- `v30` = GRCh38.p12  
- `v43` = GRCh38.p13  
- `T2T` = CHM13v2.0  
- `assembly` = reference
