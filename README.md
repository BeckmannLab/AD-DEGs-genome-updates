# AD-DEGs-genome-updates
Code for Lund et al. Differentially Expressed Genes in Alzheimer’s Disease Vary with Updates to the Human Genome Reference

Folders:
figures: code for making figures 
RAPiD: code for running for running RAPiD 
misc: miscellaneous code including code to make intermediary files used in other analyses 


The following naming conventions are used throughout the code:
hg18 = NCBI36
hg19 = GRCh37
v30 = GRCh38.p12
v43 = GRCh38.p13
T2T = CHM13v2.0
assembly = reference
